GUÍA RÁPIDA

¿Cómo se usa?

  1. Utiliza los botones para pasar las páginas.
  2. Activa el modo de edición para modificar los textos.
  3. Agrega fotografías a cada estudiante.
  4. Dibuja o sube una imagen de tu firma.
  5. Los cambios se guardan automáticamente en este navegador.
  6. Usa Guardar anuario para descargar una copia de seguridad.
  7. Usa Cargar anuario para recuperar una copia anterior.

Recuerda guardar una copia de seguridad periódicamente.
